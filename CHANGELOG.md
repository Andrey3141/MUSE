# CHANGELOG.md

## [1.2.1]

### Added
- Продолжение разработки механизма копирования музыкальных файлов во внутреннее хранилище.
- Добавление механизмов контроля конкурентного доступа к трекам.
- Система проверки обновлений через GitHub Releases с автоматической проверкой не чаще раза в 24 часа.
- Диалог уведомления о доступном обновлении с текущей и новой версией, описанием и кнопками «Позже» / «Обновить».
- Скрипт `scripts/release.sh` для автоматической сборки APK и публикации GitHub Release.

### Fixed
- Продолжение исправления логики PlaybackStateMachine.
- Исправление обработки повторного завершения воспроизведения.
- Исправление обработки изменений плейлиста.
- Исправление синхронизации фонового копирования с Room.

### Documentation
- Добавлен ROADMAP.md
- Добавлен FAQ.md
- Добавлен CHANGELOG.md
- Добавлен README.md
- Добавлен PROJECT_STRUCTURE.md и script.py

### Tests
- Разработка регрессионных тестов PlaybackStateMachine.
- Подготовка тестов конкурентного копирования файлов.

## [1.2.0]

### Added
- Добавлены механизмы claim для контроля владения треками при копировании.
- Добавлена концепция монотонного claimEpoch для защиты от устаревших операций.
- Добавлена файловая блокировка через FileLock.

### Fixed
- Начата переработка механизма конкурентного копирования.
- Улучшена защита операций обновления состояния треков.
