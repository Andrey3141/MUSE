## 📖 О проекте

**MUSE** — Android-приложение для воспроизведения и интеллектуальной организации музыкальной библиотеки.

Главная идея проекта — выйти за рамки обычного музыкального плеера. Музыка должна восприниматься не только через звук, но и через визуальный контент, а приложение должно постепенно изучать предпочтения пользователя.

MUSE строится вокруг трёх основных направлений:

- **Audio** — воспроизведение, организация и хранение музыки.
- **Visual** — обложки альбомов, изображения отдельных композиций и связанные видеоматериалы.
- **Intelligence** — анализ поведения пользователя и формирование персональных рекомендаций.

## ✨ Основные возможности

| Направление | Возможности |
|---|---|
| 🎧 **Музыкальный плеер** | Воспроизведение локальных аудиофайлов |

| 🧠 **Рекомендации** | Персональный подбор музыки на основе предпочтений |

*Перечисленные возможности отражают общую концепцию проекта. Не все функции реализованы на текущем этапе.*

## 🎨 Концепция

MUSE придерживается принципа равнозначности аудио и визуального восприятия.

<div align="center">

| 🎧 Audio | 🎨 Visual |
|:---:|:---:|
| Воспроизведение музыки | Обложки альбомов |
| Музыкальная библиотека | Изображения треков |
| Управление воспроизведением | Связанные видеоматериалы |
| Музыкальные предпочтения | Визуальная идентичность композиций |

</div>

Целевое соотношение проекта — примерно **50% аудио и 50% визуального сопровождения**.

В дальнейшем приложение должно не просто воспроизводить композиции, но и создавать целостное мультимедийное представление музыкальной библиотеки.

## 🏗 Архитектура

Проект разрабатывается модульно с разделением ответственности между основными компонентами.

```text
                    ┌──────────────────────┐
                    │      MUSE Android    │
                    └──────────┬───────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
              ▼                ▼                ▼
       ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
       │  UI / XML   │  │ ViewModel   │  │ Playback    │
       │  Interface  │  │             │  │ Service     │
       └─────────────┘  └──────┬──────┘  └──────┬──────┘
                               │                │
                               ▼                ▼
                       ┌─────────────┐  ┌─────────────┐
                       │ Repository  │  │ Media3      │
                       └──────┬──────┘  │ ExoPlayer   │
                              │         └─────────────┘
                              ▼
                       ┌─────────────┐
                       │ Room        │
                       │ Database    │
                       └─────────────┘
                              ▲
                              │
                       ┌─────────────┐
                       │ MediaStore  │
                       │ Scanner     │
                       └─────────────┘
```

### Основные компоненты

| Компонент | Назначение |
|---|---|
| **UI / XML** | Пользовательский интерфейс |
| **ViewModel** | Управление состоянием экранов |
| **Repository** | Работа с данными |
| **Room** | Локальная база данных |
| **MediaStoreScanner** | Обнаружение локальных аудиофайлов |
| **PlaybackService** | Управление воспроизведением |
| **Media3 / ExoPlayer** | Аудиодвижок |
| **WorkManager** | Фоновые задачи |

## 🚀 Разработка и запуск

### Требования

- Android Studio.
- Android SDK.
- JDK, совместимый с используемой версией Gradle.
- Устройство или эмулятор Android.

### Запуск

1. Клонируйте репозиторий.
2. Откройте проект в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Подключите Android-устройство или запустите эмулятор.
5. Выполните сборку и запуск приложения.
